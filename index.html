MODULE 02

名录不是容器，是筛子

革命文物名录常常被理解为"全量登记"，但实际上它是一套有门槛的筛选机制。 湖南明确规定名录"仅限于县级(含)以上文物保护单位"——未定级遗存在规则入口处就被排除。 山西首批名录"都是已定级的"。而宁夏、湖北、广西的名录则包含未定级条目。 省际规则差异本身，就是理解"未定级为何不可见"的关键。

MODULE 04

未定级意味着什么？

未定级不是一个"较低的等级"，而是一种制度性缺席。 国家文物保护资金主要用于全国重点文物保护单位；未定级文物通常难以纳入中央财政国家重点文物保护专项支持范围。 没有级别，就没有保护范围划定，没有管护员，没有修缮经费，甚至在建设工程中可能被直接拆除。 福建长汀启财公祠的完整链条，生动展示了从"濒临推平"到"县级文保+30万专项资金"的制度反馈路径。

保护层级筛选漏斗：从4.2万处到高等级保护
展示从全国不可移动革命文物到获得中央财政重点支持的高等级文物的层级筛选过程。注意：这是"保护层级筛选"而非严格的"资金流向"，各级文保单位与长征文物不是简单包含关系。中央财政5年累计投入革命文物保护41亿元，资金主要流向高等级文物。
数据来源：国家文物局(2023)——中央财政5年累计41亿、省级30亿、纪念馆免费开放50亿；财政部《国家文物保护资金管理办法》(2024)

红军桥：未定级，本体坍塌

未定级不可移动文物红军桥主体结构坍塌、石栏毁损严重、周边杂草丛生。同案中市级文保"红军长征纪念碑"仅附属设施损坏——二者制度处境不同，但都在检察公益诉讼介入后才获得实质性整改。2024年9月制发检察建议后，相关部门6个月未有效履职，2025年3月提起行政公益诉讼后"迅速整治"。

MODULE 06

正在改变的变量：普查与政策

第四次全国文物普查新发现文物超过13万处，2016年以来新发现长征文物点超300个，省级文保增长率超200%。 2026年3月，国家文物局发布通知明确要求"适时提升长征文物保护级别"。 制度的反馈链正在形成：普查发现 → 价值评估 → 适时提级 → 资金到位。

MODULE 07

方法说明：我们能知道什么，不能知道什么

数据新闻的诚实，在于清楚交代边界。本页所有数据均来自官方渠道或官方转载， 但未定级长征文物的全国性空间坐标和完整清单，无法从公开渠道获得。 这不是技术限制，而是制度现状——它们本就不在"可见"的范围内。
